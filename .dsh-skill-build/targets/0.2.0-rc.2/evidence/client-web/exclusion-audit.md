## Boundaries retained

- `@deepseek-ai/dsh-web-app`, `dsh-web-frontend`, and `dsh-client-web` are application shell/boot infrastructure. Exclude their runtime entries with a specific shell ownership reason; Client plugin authors use the package declaration, module artifact contract, and slot services instead.
- First-party Web search/fetch provider packages are examples of provider registration, not independent extension APIs. Their package candidates can remain excluded with each one's provider role, credential behavior, and relation to `ctx.web` stated explicitly.
- `@deepseek-ai/dsh-cordis-client-runner` handles process-local approved definitions. It is not the normal installed-package Client build path; document that distinction if included.
