# subagent 能力选型

## 对象关系

服务声明定义插件可以调用或实现的接口，具体提供方决定环境和运行能力，工具与界面消费者把结果呈现给用户或模型。配置与类型对象不能代替服务装载，Client 子路径与 Host 活对象不可跨侧混用。每个子主题说明对应包的公开关系和资源所有权。
