已按 EVALUATION.md 完成只读审核。**公开 API 用法基本匹配 rc.3，但发现 3 项应修正的交互／生命周期问题，另有 1 项列表状态问题。** 以下均有静态代码证据；尚未在浏览器复现。

1. **[P2] 并发复制会产生多个计时器，旧结果可能覆盖新反馈。**
   [SessionIdPanel.tsx:69](<isolated-fixtures>/with-skill/packages/dsh-session-id/src/client/SessionIdPanel.tsx:69) 仅在点击时清理计时器。连续点击 A、B，若两次 Promise 都尚未完成，两次成功回调仍各自创建计时器；后创建者覆盖保存的句柄，较早计时器可能提前清除新反馈。旧请求晚到的失败也能覆盖新成功。
   **最小修正：**用递增请求序号，仅允许最新请求更新状态；成功回调创建计时器前再清理旧句柄。补 deferred Promise 测试，覆盖连续点击、逆序完成及成功／失败交错。

2. **[P2] 等待复制时关闭面板或卸载，晚到成功仍会创建计时器。**
   [SessionIdPanel.tsx:65](<isolated-fixtures>/with-skill/packages/dsh-session-id/src/client/SessionIdPanel.tsx:65) 的 cleanup 只能清理当时已有的计时器；未完成 Promise 随后仍执行 `setStatus` 和 `setTimeout`。关闭面板、过滤掉该行、插件卸载均可能触发。不能据此声称 React 会崩溃，但确有卸载后异步工作残留。
   **最小修正：**cleanup 标记 owner 已失效并使请求序号失效；所有完成分支检查 owner 和序号。`writeClipboard` 无取消参数，只能忽略晚到结果，不能承诺撤回已发出的系统复制。
   现有[生命周期测试:251](<isolated-fixtures>/with-skill/packages/dsh-session-id/tests/session-id-panel.spec.tsx:251) 都先等待复制完成，未覆盖上述窗口。

3. **[P2] 自制弹窗缺少键盘和焦点生命周期。**
   [SessionIdEntry.tsx:49](<isolated-fixtures>/with-skill/packages/dsh-session-id/src/client/SessionIdEntry.tsx:49) 自建 portal；[SessionIdPanel.tsx:138](<isolated-fixtures>/with-skill/packages/dsh-session-id/src/client/SessionIdPanel.tsx:138) 只有遮罩／关闭按钮，没有 Escape、初始焦点、Tab 圈定和关闭后恢复焦点的实现。`aria-modal` 本身不提供这些行为。
   **最小修正：**复用公开 `Modal`，传入 `open`、`onClose`、本地化 `title`、`closeLabel`，搜索框标记 `data-modal-autofocus`，移除重复 portal／遮罩；复制请求的清理仍由业务组件负责。

4. **[P2] 首次列表尚未到达时误报“暂无会话”。**
   [SessionIdPanel.tsx:163](<isolated-fixtures>/with-skill/packages/dsh-session-id/src/client/SessionIdPanel.tsx:163) 忽略 `snapshot.phase`。SDK 明确区分 `pending` 和 `ready`；首次成功拉取前的空列表不能证明没有会话。
   **最小修正：**`pending` 显示加载状态，仅在 `ready` 且无行时显示空状态；补 pending→ready 测试。

| Sidebar | `@deepseek-ai/dsh-client-ui-sidebar/client` 提供契约扩展；`sidebar.footer.action` 为 root/list slot，owner 传 `wide: boolean`。现有 `ctx.slots.inject` → `register({name,id,locale,inject}, Component)` 匹配。 |
