- `packages/credentials/authorization/package.json` exports `.`, `./types`, `./invariant`; `src/index.ts` injects credentials, registers flow and single-flight begin/cancel. Base patch mounts authorization. No source `@deprecated` found in relevant files.

Base patch mounts settings; Web app patch mounts settings controller/UI separately. Cookbook `docs/cookbook/adding-a-settings-card.md` supplies author task, not stronger behavior than code.
- `packages/interaction/permission-presets/package.json` exports root, `./types`, `./client`, generated `./typert`, `./remote`, and invariant companion. `src/{index,types}.ts` owns preset table, Service, projection, Session events, catalog and command. Base patch mounts it; Web patch mounts Client UI. `docs/subsystems/permission-presets.md` supplements semantics.

## Behavior and limits observed in source

- `CredentialProvider.resolve/describe/set/unset` operates on env-name refs, while `readRecord/describeRecord/listRecords/modifyRecord/deleteRecord` operates on owner-scoped record keys. `modifyRecord` is only record write path. Events are emitted after committed provider changes and fan-out contains normal observer failures.
- `AuthorizationService.registerFlow` has duplicate-key failure and disposer-driven cancellation. `begin` validates key/method/busy before pre-aborted signal; one in-flight per key. It demands record commit observed during attempt and still present; prompt decline/cancellation settle cancelled. Race with a flow ignoring abort can leave private work running; flow must implement cancellation.
- `SettingsForms.write` validates a JSON-shaped clone, volatile-only edits, full Config, revision and active entry before a config-editor edit. `mutate` is path addressed for redacted UI. Remote reads are redacted by controller; Host `describe()` can be unredacted, so plugin authors must not forward it blindly.
- `PermissionPresetService` requires shell/approval/sessions/projections and confining shell. It preserves durable preset intent and writes actual knobs through canonical setters; `auto` only from fixed live integration. `custom` is derived, not switchable.
