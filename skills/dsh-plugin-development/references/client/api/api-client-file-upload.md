# file-upload：插件接入

## 对象关系

文件上传以 receipt/binding 交给提交路径；浏览器进度不等于 Session 已采纳附件。上传失败或取消不应保留可提交的伪 receipt；临时资源归上传服务与调用信号所有，业务持久事实须经 Host 的提交链建立。
