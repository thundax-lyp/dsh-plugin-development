# Skill 维护

本产物适用 `@deepseek-ai/dsh-agent@0.2.1-rc.3`。消费项目版本不同，先重新取得匹配版本的 Skill；不要局部替换签名或把另一个版本的例子混进当前契约。

维护仓库的创建流程从精确发布 tag 重新提取公开声明、运行时、组合、门禁、测试与文档任务，完成逐项语义裁决后冻结，构建新的完整目录。此产物与其 source-map 都不是下一版本的知识输入。只在新目录通过结构、离线链接、类型与代表性装载行为验证后整体替换。

验证分为声明编译、包解析/构建、Loader 组合、业务行为和用户可见结果。Host 与 Client 分开编译；Remote 先运行所属生成器。自动链接与签名检查不能证明取消、权限、清理、恢复或浏览器交互；每条主要任务按其完成判据执行。分发目录只保留读者契约，维护者运行记录保留在维护仓库。
